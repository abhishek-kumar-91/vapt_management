# `lib/` API reference

The exports of every module in `lib/`, grouped by file. Signatures are simplified for reading. The source is authoritative.

## `lib/sop.ts`: SOP constants

| Export | Value / type |
| --- | --- |
| `PRODUCT_ORDER` | `string[]`. Display order of known product ids |
| `SEVERITIES` | `["Critical", "High", "Medium", "Low"]` |
| `AREA_STATUSES` | `["To Do", "In Testing", "Blocked", "Tested"]` |
| `FINDING_STATUSES` | All eight finding statuses |
| `ACTIVE_FINDING_STATUSES` | `Open`, `Triaged`, `In Fix`, `Ready for Retest` |
| `EXIT_STATUSES` | `Rejected`, `Risk Accepted`, `Won't Fix` |
| `CLOSED_STATUSES` | `Closed` + `EXIT_STATUSES` |
| `PRODUCT_STATUSES` | `Not started`, `In progress`, `Paused`, `Baseline complete`, `Continuous` |
| `SEVERITY_DAYS` | `{ Critical: 7, High: 30, Medium: 90 }` |
| `RETEST_WORKDAYS` | `2` |
| `CLOSEOUT_COVERAGE` | `80` |
| `TIER_WEIGHT` | `{ 1: 3, 2: 2, 3: 1 }` |
| `SEVERITY_WEIGHT` | `{ Critical: 10, High: 5, Medium: 2, Low: 0.5 }` |
| `CYCLE_RULES` | `CycleRule[]`. `{ key, title, source, months?, days?, eventBased? }` |
| `SOP_RULES` | `string[]`. Human-readable rules shown in Settings |

## `lib/dates.ts`: ISO date helpers

All values are local `YYYY-MM-DD` strings. Working days are Monday to Friday, with no holiday calendar.

```ts
todayIso(): string
toIso(date: Date): string
formatDate(value?: string, options = { day: "numeric", month: "short" }): string   // "14 Nov", or "—" when empty
LONG_DATE: Intl.DateTimeFormatOptions                                               // "14 Nov 2026"
isWorkday(date: Date): boolean
workdaysBetween(from?: string, to?: string): number   // working days after `from`, up to and including `to`
addWorkdays(from: string | undefined, count: number): string
addMonths(value: string | undefined, count: number): string   // clamps to the end of the month (31 Jan + 1 → 28/29 Feb)
addDays(value: string | undefined, count: number): string
dateDiff(from?: string, to?: string): number                  // calendar days, to − from
```
